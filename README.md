# InterviewPro

An AI interview coach for mobile. Pick a role and interview type, answer questions generated by AI, and get a score with strengths, improvements and a sample better answer. Past interviews are saved on the phone.

## Features
- Choose role, interview type and number of questions
- AI-generated questions that don't repeat
- AI scoring (0-10) with detailed feedback
- Session summary with average score
- History of past interviews saved on the device

## Tech stack
- App: React Native + Expo
- Backend: Node.js + Express
- AI: Claude API (key kept on the server, never in the app)
- Storage: AsyncStorage

## How it works
Phone app -> Node.js server (holds the API key) -> AI API

## Run it locally
1. Server: cd interviewpro-server, npm install, copy .env.example to .env and add your API key, then node server.js
2. App: cd InterviewPro, npm install, set API_URL in api.js to your laptop's IP address, then npx expo start
3. Scan the QR code with Expo Go (phone and laptop on the same Wi-Fi)
